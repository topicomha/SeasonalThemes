## Using These Themes

To use these themes with Oh My Posh:

1. Set the configuration file in your PowerShell profile:
   ```powershell
   oh-my-posh init pwsh --config "C:\path\to\SeasonalThemes\[Month]\davids-[Month].omp.json" | Invoke-Expression
   ```

2. For automatic theme switching based on the current month, add the following to your PowerShell profile:
   ```powershell
   $currentMonth = (Get-Date).ToString("MMMM")
   $themePath = "C:\path\to\SeasonalThemes\$currentMonth\davids-$currentMonth.omp.json"
   if (Test-Path $themePath) {
       oh-my-posh init pwsh --config $themePath | Invoke-Expression
   } else {
       # Default theme if monthly theme not found
       oh-my-posh init pwsh --config "C:\path\to\SeasonalThemes\test.omp.json" | Invoke-Expression
   }
   ```

For more information on customizing Oh My Posh themes, refer to the [official documentation](https://ohmyposh.dev/docs/configuration/overview).
